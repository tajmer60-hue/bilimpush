# 🎓 Bilim+ — школьная база Казахстана

Веб-приложение для подтягивания школьной базы по основным предметам (5–11 классы, программа Казахстана, язык интерфейса — русский): **читай теорию → проходи тест → провалил? система соберёт новый адаптивный тест с учётом твоих ошибок.**

## Предметы (9 шт.)

| Предмет | Разделы | Тем в стартовом банке |
|---|---|---|
| 📐 Математика | Алгебра (5–11), Геометрия (7–10) | 11 |
| ⚛️ Физика | Механика, Электричество и тепло | 5 |
| 🧪 Химия | Общая, Органическая | 5 |
| 🧬 Биология | Общая биология, Человек | 4 |
| 🌍 География | Физическая, География Казахстана | 4 |
| 🏹 История Казахстана | Древний/средневековый период, XX–XXI вв. | 5 |
| 🏛️ Всемирная история | Древний мир и Средневековье, Новое/новейшее время | 4 |
| ⚖️ Основы права | Конституционные основы РК, Права человека и отрасли права | 5 |
| 💻 Информатика | Системы счисления, Алгоритмы, Сети и ИБ | 3 |

**Стартовый банк: 46 тем, 462 вопроса** (по 10–12 на тему) + теория по каждой теме. Контент легко расширяется через JSON-файлы или админ-API (см. ниже).

## Быстрый старт

```bash
cd backend
pip install -r requirements.txt
python3 run.py
# открой http://localhost:8000
```

При первом запуске база данных (`backend/bilim.db`) создаётся и наполняется контентом из `backend/content/*.json` автоматически.

**Учётки по умолчанию:**
- Админ: `admin@bilim.kz` / `admin123` (смените в проде через переменные окружения `BILIM_ADMIN_EMAIL`, `BILIM_ADMIN_PASSWORD`)
- Ученики регистрируются сами через экран регистрации.

**Прогон E2E-тестов** (сервер должен быть запущен): `python3 e2e_test.py` — проверяет регистрацию, выдачу теста, провал, адаптивный ретест, сдачу, дашборд, защиту от повторной отправки и авторизацию.

## Как работают адаптивные тесты

1. Ученик читает теорию темы → нажимает «Пройти тест».
2. Сервер собирает тест из банка темы: **10 вопросов**, при первой попытке — сбалансированно по сложности.
3. Проверка: проходной балл **70%**. После отправки — детальный разбор каждого вопроса с пояснением.
4. **Тест провален → доступна кнопка «Пройти новый тест»**. Новый тест собирается адаптивно:
   - до 60% вопросов — те, где ученик ошибался раньше (по всем попыткам темы);
   - остальные — новые вопросы из банка, которых ещё не было;
   - вопросы последней попытки не повторяются, пока позволяет банк.
5. Тема получает статус: `new` → `read` (прочитана) → `passed` (сдана). Лучший результат и число попыток сохраняются.
6. На главной — дашборд: прогресс по предметам, **слабые темы** (читал, но не сдал) и история результатов.

## Архитектура

```
bilim/
├── backend/                 # FastAPI + SQLAlchemy + SQLite
│   ├── app/
│   │   ├── main.py          # точка входа, раздаёт API + фронтенд
│   │   ├── models.py        # User, Subject, Section, Topic, Question, Attempt, Answer, Progress
│   │   ├── routers/
│   │   │   ├── auth.py      # регистрация/вход, JWT
│   │   │   ├── content.py   # предметы/разделы/темы/теория
│   │   │   ├── tests.py     # ★ адаптивная генерация тестов и проверка
│   │   │   ├── progress.py  # дашборд, слабые темы
│   │   │   └── admin.py     # импорт контента, CRUD вопросов (роль admin)
│   │   ├── security.py      # pbkdf2-пароли, JWT
│   │   └── seed.py          # автонаполнение БД при старте
│   ├── content/*.json       # контент: предмет → разделы → темы (теория + вопросы)
│   └── run.py
├── frontend/                # SPA на чистом JS (без сборщиков и CDN — работает офлайн)
│   ├── index.html
│   ├── css/style.css
│   └── js/{api.js, app.js}
├── docs/ARCHITECTURE.md     # ТЗ, схема БД, план развития и мобильной версии
└── e2e_test.py
```

**Стек:** Python 3.11, FastAPI, SQLAlchemy 2, SQLite, PyJWT; фронтенд — vanilla JS SPA (hash-роутинг), mobile-first CSS.

## API (кратко)

| Метод | Путь | Описание |
|---|---|---|
| POST | `/api/auth/register` / `/login` | регистрация/вход → JWT |
| GET | `/api/subjects` | дерево предметов с прогрессом пользователя |
| GET | `/api/topics/{id}` | теория темы + статус |
| POST | `/api/topics/{id}/test` | собрать тест (первый или адаптивный ретест) |
| POST | `/api/attempts/{id}/submit` | проверить ответы → результат + разбор |
| GET | `/api/progress` | дашборд: статистика, слабые темы, история |
| POST | `/api/admin/import-all` | (admin) переимпорт всего контента |
| POST | `/api/admin/import-file` | (admin) импорт предмета из загруженного JSON |
| POST/DELETE | `/api/admin/questions` `/api/admin/topics` | (admin) добавление/удаление |

Полная документация с примерами: `http://localhost:8000/docs` (Swagger UI).

## Добавление контента

1. Скопируйте любой файл из `backend/content/` как шаблон.
2. Опишите предмет → разделы → темы: `theory` (HTML) + массив `questions` (`text`, `options`, `correct` — индекс или массив индексов для `multiple`, `difficulty` 1–3, `explanation`).
3. Перезапустите сервер (импорт идемпотентен: существующие темы/вопросы не дублируются) или вызовите `POST /api/admin/import-all` под админом.
